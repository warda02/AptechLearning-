# 🎓 Aptech Learning App — Flutter

A Flutter mobile application for Aptech Learning Institute — built to support student learning and course management.

## ✨ Features
- 📚 Course content browsing
- 👩‍🏫 Student-instructor interaction
- 📱 Cross-platform (Android & iOS)
- 🎨 Clean Material Design UI

flutter run
